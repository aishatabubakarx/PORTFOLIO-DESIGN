# Aishat Abubakar Portfolio

## Publish on GitHub Pages
1. Create a repository on GitHub (for a main address use the name `aishatabubakar.github.io`, matching your username).
2. Upload everything from this folder to the repository root, keeping the folder structure.
3. Open Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then save.
4. The site goes live within a few minutes.

## Add new work
1. Put videos in `media/videos/` and images in `media/images/`.
2. For each video, put a preview image (jpg) in `media/posters/`.
3. Open `works.js`, copy one block, and change the title, category, file paths and ratio.
4. Commit the change on GitHub. The new item appears at the top of the grid.

Keep each file under 100 MB, which is the GitHub limit. Compressed mp4 (H.264) files load fastest.
